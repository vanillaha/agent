## 下一项：M4 去重与版本关系识别

> 2026-10-21：M5 已完成归档（TASK-003），M3 转入进行中，本条成为"下一项"。
> M5 规格已随验收移入 `已完成任务.md`。

- 任务名称：去重与版本关系识别
- 为什么做它：M2 的跨源候选未去重（同一论文多源各出现一次）；M5 落库后同一论文的 preprint/会议/期刊版本会各自成 paper 记录。去重与版本族是"证据不重复计数"与"引用指向权威版本"的前提。
- 目标：
  - 确定性合并：DOI / arXiv ID / 标题+年份 弱键逐级匹配，合并为同一 `paper_id`；
  - 版本族归并：以 arXiv ID 与 DOI 关系建 `VersionRelation`，识别 preprint → 会议/期刊版链条，标记权威版本；
  - 落库：`papers` 表升级支持版本关系查询。
- 输入输出：输入跨源 `SourceCandidate` 汇总与已入库论文；输出去重后的论文清单与版本族视图。
- 边界（不做）：不做语义相似度合并（LLM/嵌入判重是 M6 之后的事）；不自动改写用户已引用的版本。
- 验收要点：
  - 同一论文四源检索 → 合并为 1 条记录，字段冲突有可解释的优先级规则；
  - preprint 与其期刊版归入同族，权威版本标记可测；
  - 全程离线可测（假数据沿用 M2 模式）。
