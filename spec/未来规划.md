## 下一项：M3 开放获取全文下载与合规层

> 2026-10-21 取舍决定：M2 完成后选择 M5 先行（证据链地基 + 提前排雷 Docling/py3.13），
> 本任务顺延到 M5 之后。原"下一项为 M5"的规划已移入 `当前开发任务.md`。

- 任务名称：开放获取全文下载与合规层
- 为什么做它：闭合联网链路（检索 → 下载 → 落到本地文件）。M2 已备齐 `oa_status` / `oa_url` / `license`（Crossref 是唯一许可证来源），本层据此判断"能不能合法下载"。
- 目标：
  - 下载前合规检查：仅当 OA 状态开放且许可证允许时下载；不绕过付费墙。
  - 下载执行：文件类型校验（`%PDF` 魔数）、大小上限、下载记录 `DownloadRecord` 落库。
  - 无法获取全文时只保留元数据与链接（课程规范要求）。
- 输入输出：输入 M2 的 `SourceCandidate`（含 OA 链接与许可证）；输出 `DownloadRecord` 与本地文件路径。
- 边界（不做）：不做解析（M5 已做）；不处理非 PDF 产物；不做并发抓取。
- 验收要点：
  - `NOT_OPEN_ACCESS` / `DOWNLOAD_FAILED` / `UNSUPPORTED_FILE_TYPE` 行为可测。
  - 全部测试离线（假 HTTP 客户端 + 脱敏样本，沿用 M2 的 `fakes.py` 模式）。
  - 禁网保护：与 M2 相同，未授权时一个请求都不发。
